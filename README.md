## 🚀 Key Features

* **In-Browser Kali Pwnbox Terminal**: Realistic CLI supporting `nmap`, `gobuster`, `hydra`, `nc`, `sqlmap`, `curl`, `ssh`, and privilege escalation utilities (`sudo -l`, `linpeas`).
* **Virtual Target Machines ("Boxes")**: Multi-tier simulated machines with authentic vulnerability chains (Log4j CVE-2021-44228, SQL Injection, SMB EternalBlue, Sudo misconfigurations).
* **Interactive Attack Graph (BloodHound-style)**: Live visual enterprise network topology mapping perimeter DMZs, pivot routers, and internal Domain Controllers.
* **Autonomous AI Co-Pilot ("GhostOps AI")**: Socratic hints, automated payload forge, and autonomous red team attack demonstration.
* **In-Browser Web Proxy & Repeater (Burp Suite clone)**: Raw HTTP request interception, header tampering, and instant replaying.
* **CTF Progression & Scoreboard**: Flag submission engine (`ROOTRANGE{...}`), cryptographic verification, and rank advancement.

## 🛠️ Quickstart

```bash
# 1. Clone the repository
git clone https://github.com/Dotify71/ROOTRANGE.git
cd ROOTRANGE

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```
